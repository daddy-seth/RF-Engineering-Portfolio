# 📊 KPI Analysis

## Overview

This folder contains examples of LTE and 5G Key Performance Indicator (KPI) analysis performed during drive testing and post-swap verification.

---

## KPIs Reviewed

### 📶 RSRP (Reference Signal Received Power)

- Measures signal strength.
- Strong signal generally provides better coverage and user experience.

---

### 📡 RSRQ (Reference Signal Received Quality)

- Measures signal quality.
- Helps identify network congestion and interference.

---

### 📈 SINR (Signal to Interference plus Noise Ratio)

- Measures signal clarity.
- Higher SINR values indicate better radio conditions.

---

### 🛰 PCI (Physical Cell Identity)

- Confirms that the serving cell is correctly identified.
- Used to detect PCI conflicts or confusion.
